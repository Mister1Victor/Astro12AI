# Astro12AI — Состояние проекта

**Версия:** 2.0.9
**Дата:** 03.08.2026
**Статус:** Production Ready (Telegram-бот на Render)

---

## Что работает

- **Telegram Bot** (aiogram) — хостинг Render, self-ping для uptime
- **Парсинг ZET-логов** — планеты, знаки, дома, аспекты (латиница и кириллица)
- **Лунные дни** — 30 дней, полные авторские определения
- **AstroRetriever** — поисковый движок на BM25 + авторские фильтры + **авторский реранкинг** (v2.0.9)
- **Детектор типа запроса** (`build_task_hint`) — формирует «Задачу» под структуру запроса: разбор ситуации / взаимодействие планет через аспект / контекст сферы дома / контекст темы вопроса (v2.0.9)
- **Классификатор тем вопроса** (`classifier.py`) — love/money/health/spirit, подключён к реранкингу и расширению запроса (v2.0.9)
- **AUTHOR_DEFINITIONS** — определения для 12 планет, 12 домов, 6 аспектов, 30 лунных дней
- **ASTRO_TERMS** — ключевые слова знаков и домов (для расширения запроса)
- **FORBIDDEN** — чёрный список общеастрологических слов (Плутон/Нептун/Уран/Юпитер/Церера/Эрида)
- **Кнопка «Перефразировать»** — повторный запрос последнего вопроса пользователя
- **LLM** — Groq (llama-3.3-70b-versatile), fallback на OpenRouter/Gemini через `.env`
- **Таро-модуль** (`tarot_chart.py`) — генерация карты «22 старших аркана + зодиак» (matplotlib)

## Метрики

- Время ответа: ~2–3 сек
- Токены на запрос: ~2000–3000
- k (документов из BM25): 4, расширяется до 10 перед фильтрацией

## Известные расхождения (технический долг)

1. **Морфология планет.** `extract_entities` не ловит падежные формы планет (напр. «расскажи про Лун**у**» → сущность не найдена, т.к. в `REPLACE` нет падежей планет). Не блокирует основной сценарий (ZET-логи и положения в знаке/доме), но общие вопросы в падеже распознаются как general.
2. **7 дом** закомментирован в `ASTRO_TERMS` (weights.py), но есть в `AUTHOR_DEFINITIONS`. Ключевые слова 7 дома не участвуют в расширении запроса.
3. **Таро-модуль:** символ `⚹` (центр карты) отсутствует в шрифте DejaVu Sans → matplotlib рисует пустой глиф + warning.
4. **output/**: код сохраняет в `astrology_tarot_big.png`, git трекает устаревший `astrology_tarot_light_v4.png`.
