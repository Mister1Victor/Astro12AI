# AI MEMORY — Astro12AI

**Версия:** 2.0.9 · **Дата:** 03.08.2026

## Паспорт

- **Проект:** Astro12AI
- **Автор:** Виктор Слободнюк
- **Назначение:** ИИ-консультант Высшей Школы Астрологии «12 Планет».
- **Суть:** не вычисление карты, а максимально точная интерпретация авторской базы знаний.

## Миссия

Создать профессиональную интеллектуальную систему Высшей Школы Астрологии «12 Планет» (чат-бот + продакшн-приложение для Google Play), которая отвечает **исключительно** на основании авторской базы знаний Школы Виктора Слободнюка.

**Главная цель:** максимальная точность интерпретаций + устойчивая монетизация.

## Главное правило (Правило №1 Astro Core)

Единственный источник истины — материалы Школы Виктора Слободнюка.

- Общеастрологические трактовки **запрещены**.
- Все определения должны соответствовать `ASTRO_TERMS` и `AUTHOR_DEFINITIONS` (`core/knowledge/weights.py`).
- При конфликте между общеизвестной и авторской трактовкой **всегда** выбирается трактовка Школы.
- Если информации нет в базе — модель честно сообщает об этом, а не придумывает ответ.

## Текущая архитектура поиска

```
User Query → build_task_hint (тип запроса → «Задача»)
  → Normalize → expand_query (+ ключевые слова + тема вопроса) → BM25 (топ-10)
  → remove_duplicates → filter_short_documents → filter_by_entities
  → limit_same_source → force_school_definition
  → FORBIDDEN-фильтр → sort_documents (авторский реранкинг: буст по ключевым словам Школы + теме вопроса)
  → inject_context_blocks (AUTHOR_DEFINITIONS + ASTRO_TERMS)
  → LLM
```

Подробности — в `docs/ARCHITECTURE.md`. Вся логика поиска — в `core/rag/engine.py`.

## Принципы разработки

1. Проект всегда в рабочем состоянии.
2. Одно изменение — один Git-коммит.
3. Сначала локальная проверка, потом GitHub, потом Render.
4. Не переписывать большие куски кода без необходимости.
5. Каждая новая функция сопровождается документацией.
6. `core/` не зависит от Telegram / Android / веба.
7. Улучшения поиска — только внутри `AstroRetriever` (`core/rag/engine.py`).

## Известный технический долг

- Морфология планет: `extract_entities` не ловит падежные формы (напр. «расскажи про Луну»), т.к. в `REPLACE` нет падежей планет. Не блокирует основной сценарий.
- 7 дом закомментирован в `ASTRO_TERMS` (но есть в `AUTHOR_DEFINITIONS`).
- Таро: символ `⚹` в центре отсутствует в DejaVu Sans.

## Долгосрочное видение

Авторские определения → Авторские сущности → Авторские связи → Поиск по смыслу → LLM.

BM25 остаётся механизмом первичного отбора; финальное ранжирование строится на авторских сущностях Школы, а не на совпадении слов.
