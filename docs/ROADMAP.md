## 🎯 Миссия проекта

Создать профессиональную интеллектуальную систему Высшей Школы Астрологии «12 Планет», которая отвечает **исключительно** на основании авторской базы знаний Школы Виктора Слободнюка.

**Главная цель:** Максимальная точность интерпретаций + устойчивая монетизация.

## 🛡 План восстановления в случае сбоя

### Сценарий 1: Render упал и не восстанавливается

**Действия:**
1. Проверить логи на Render Dashboard
2. Если код сломан → откатить последний коммит:
   ```bash
   git revert HEAD
   git push
   ```
3. Если Render не помогает → перенести на другой хостинг:
   - Railway.app (бесплатный тариф)
   - Fly.io (бесплатный тариф)
   - VPS (Timeweb, Beget — от 200 руб/мес)

**Время восстановления:** 30 минут - 2 часа

---

### Сценарий 2: Groq API перестал работать

**Действия:**
1. В `.env` изменить:
   ```env
   LLM_PROVIDER=openrouter
   MODEL_NAME=meta-llama/llama-3.3-70b-instruct
   OPENROUTER_API_KEY=sk-or-ваш_ключ
   ```
2. Перезапустить бот

**Время восстановления:** 5 минут

---

### Сценарий 3: Потеряли доступ к GitHub

**Действия:**
1. Локальная копия у вас есть (вы же разрабатывали локально)
2. Создать новый репозиторий
3. Запушить локальную копию:
   ```bash
   git remote set-url origin новый_url
   git push -u origin main
   ```

**Время восстановления:** 15 минут

---

### Сценарий 4: Telegram Bot перестал отвечать

**Действия:**
1. Проверить логи на Render
2. Если ошибка в коде → исправить и запушить
3. Если Telegram API проблема → подождать (обычно проходит за 10-30 минут)
4. В крайнем случае → создать нового бота через @BotFather, обновить `TELEGRAM_TOKEN`

**Время восстановления:** 10 минут - 1 час
