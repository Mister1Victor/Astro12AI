# Миссия проекта

Создать профессиональную интеллектуальную систему Высшей Школы Астрологии «12 Планет», которая отвечает исключительно на основании авторской базы знаний Школы.

Главная цель — максимальная точность интерпретаций.

Не чат-бот общего назначения.

Не "ещё один GPT".

А экспертная система Школы 12 Планет.

---

# Главные принципы

1. Проект всегда должен оставаться рабочим.

2. Каждое изменение небольшое.

3. Каждое изменение обратимо.

4. Сначала качество.

Потом функциональность.

Потом красота.

5. Не переписывать работающий код.

6. Не усложнять архитектуру без необходимости.

7. Любая новая возможность должна увеличивать качество консультации.
