# CHANGELOG

## v0.8.0

### Архитектурное решение

Принято решение отказаться от развития обычного BM25-поиска.

Проект переходит на собственую архитектуру Semantic School Engine.

Основные принципы:

- поиск по астрологическим сущностям;

- авторские определения Школы;

- расширение пользовательского запроса через словарь Школы;

- BM25 становится только индексом;

- AstroRetriever становится главным интеллектуальным поисковым модулем проекта.

Это крупнейшее изменение архитектуры с момента создания Astro12AI.
