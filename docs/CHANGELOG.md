Формат: версии проекта. Подробности — в commit-сообщениях Git.

## [2.0.9] — 03.08.2026

### Добавлено (пункт 2 Roadmap — Оптимизация ответа)
- **Авторский реранкинг подключён.** Методы `calculate_score`/`sort_documents` вызываются в `search()` (раньше были мёртвым кодом). Документы ранжируются по совпадению с авторскими ключевыми словами Школы.
- **Детектор типа запроса** `AstroRetriever.build_task_hint(query)` — формирует «Задачу» под структуру запроса вместо жёсткого «Комплексный анализ по всем сферам»:
  - 1 планета + 1 знак → разбор ситуации (функции планеты через качества знака);
  - 2+ планеты + аспект → анализ взаимодействия планет через аспект;
  - + дом(а) → анализ в контексте сферы жизни (по авторскому определению Школы);
  - + тема вопроса (love/money/health/spirit) → анализ в контексте вопроса;
  - общий разбор → комплексный анализ.
- **`topic_score`** в `calculate_score` — буст документов по теме вопроса (реализация «конкретный вопрос → приоритет словам контекста»).
- **Классификатор тем** `core/rag/classifier.py` (`classify_question`) подключён к `engine.py` (раньше не импортировался). Тема вопроса также подмешивается в `expand_query`.

### Изменено
- `main.py:379` — жёсткий суффикс «Задача: Комплексный анализ по всем фундаментальным сферам» заменён на условный через `astro_retriever.build_task_hint(processed_query)`.
- `expand_query` — срез ключевых слов уменьшен с `[:8]` до `[:5]` на сущность (снижение раздувания запроса); добавлены слова темы вопроса.
- `calculate_score` — убран дублирующий `authority_score` (полностью копировал `astro_terms_score`); `authority_score` оставлен как тонкая обёртка для обратной совместимости.

### Принципы (соблюдены)
- BM25 остаётся первичным механизмом. Без embeddings / внешних реранкеров / векторных БД.
- Все изменения — внутри `core/rag/engine.py` + одна строка в `main.py`. `core/` не зависит от Telegram.
- `AUTHOR_DEFINITIONS`, `ASTRO_TERMS`, `FORBIDDEN`, `SYSTEM_PROMPT` — без изменений.

### Проверено
- Синтаксис/компиляция `engine.py`, `classifier.py`, `main.py`.
- `build_task_hint` на 6 сценариях (планета+знак, аспект, дом, тема, комбинации).
- Полный `search()` на реальной базе (351 фрагмент): авторский блок остаётся на 1-м месте во всех тестах.
