# Расшифровка параметров конфигурации Astrology Tarot

Этот документ содержит подробное описание всех параметров из блока `CONFIG` в скрипте генерации астрологической карты Таро. Параметры сгруппированы по логическим разделам.

---

## 1. Общий масштаб

| Параметр | Значение | Описание |
|----------|----------|----------|
| `SCALE` | `1.3` | Глобальный коэффициент масштабирования всех размеров (радиусов, ширины, размеров карт). Увеличение этого значения делает всю карту крупнее без изменения пропорций. |
| `ZODIAC_SCALE` | `1.2` | Дополнительный масштаб только для зодиакального круга (умножается на `R_ZODIAC`, `R_ZODIAC_LABEL`, `R_HOUSE`). Позволяет расширить зодиакальный круг относительно остальных элементов. |

---

## 2. Размеры карт (Арканов)

| Параметр | Значение | Описание |
|----------|----------|----------|
| `CARD_W_OUTER` | `0.18` | Ширина карт внешнего круга (0–XI) в относительных координатах. |
| `CARD_H_OUTER` | `0.22` | Высота карт внешнего круга. |
| `CARD_W_INNER` | `0.18` | Ширина карт внутреннего круга (XII–XXI). |
| `CARD_H_INNER` | `0.22` | Высота карт внутреннего круга. |

Все размеры карт умножаются на `SCALE`.

---

## 3. Зодиакальный круг

| Параметр | Значение | Описание |
|----------|----------|----------|
| `R_ZODIAC` | `1.0` | Внешний радиус зодиакального кольца (до умножения на `SCALE` и `ZODIAC_SCALE`). |
| `ZODIAC_WIDTH` | `0.20` | Радиальная ширина (толщина) зодиакального кольца. Увеличение этого значения делает цветные сектора шире, что даёт больше места для подписей и символов. |
| `R_ZODIAC_LABEL` | `0.94` | Радиус, на котором размещаются символы и названия знаков зодиака (после умножения на `SCALE` и `ZODIAC_SCALE`). |
| `R_HOUSE` | `0.83` | Радиус, на котором располагаются кружки с номерами домов (после масштабирования). |
| `HOUSE_CIRCLE_R` | `0.040` | Радиус самих кружков домов (без дополнительного масштаба, умножается только на `SCALE`). |

---

## 4. Контурные кольца

Эти кольца не имеют заливки, они просто обводят карту тонкими линиями.

| Параметр | Значение | Описание |
|----------|----------|----------|
| `RING_RADII` | `[1.0, 0.86, 0.72, 0.56, 0.36]` | Список радиусов колец (все умножаются на `SCALE`). Первое кольцо совпадает с внешней границей зодиака. |
| `RING_LW` | `[3.0, 2.0, 1.5, 1.5, 2.0]` | Толщина линий для каждого кольца (в пунктах). |
| `RING_ALPHA` | `[0.9, 0.7, 0.5, 0.5, 0.7]` | Прозрачность линий колец (0 – невидимо, 1 – полностью видимо). |

---

## 5. Арканы (позиционирование карт и стрелок)

### 5.1 Внешний круг (0–XI)

| Параметр | Значение | Описание |
|----------|----------|----------|
| `OUTER_RAD_CARD` | `0.66` | Расстояние от центра до центров карт внешнего круга (умножается на `SCALE`). |
| `OUTER_ARROW_R` | `0.79` | Радиус, на котором рисуются стрелки направления для внешнего круга (умножается на `SCALE`). |
| `OUTER_ARROW_SPAN` | `5` | Половина угла дуги стрелки (в градусах). Определяет длину каждой маленькой дуги-стрелки. |

### 5.2 Внутренний круг (XII–XXI)

| Параметр | Значение | Описание |
|----------|----------|----------|
| `INNER_RAD_CARD` | `0.42` | Расстояние от центра до центров карт внутреннего круга (умножается на `SCALE`). |
| `INNER_ARROW_R` | `0.35` | Радиус, на котором рисуются стрелки направления для внутреннего круга. |
| `INNER_ARROW_SPAN` | `7` | Половина угла дуги стрелки для внутреннего круга (больше, чем у внешних, чтобы дуги были заметнее). |

---

## 6. Глобальные стрелки (направления обхода)

Это большие пунктирные дуги со стрелками, показывающие общее направление движения (по часовой / против часовой).

| Параметр | Значение | Описание |
|----------|----------|----------|
| `GLOBAL_OUTER_DIAM` | `2.15` | Диаметр внешней глобальной дуги (умножается на `SCALE`). Дуга рисуется от угла 195° до 345°. |
| `GLOBAL_INNER_RADIUS` | `0.21` | Радиус внутренней глобальной дуги (по часовой). Дуга рисуется от 165° до 15°. |

---

## 7. Повороты и порядок обхода

| Параметр | Значение | Описание |
|----------|----------|----------|
| `ROTATE_OUTER` | `-15` | Смещение (поворот) всех карт внешнего круга в градусах. Отрицательное значение – по часовой, положительное – против часовой. |
| `ROTATE_INNER` | `-15` | Смещение внутреннего круга. |
| `OUTER_ORDER` | `True` | Если `True`, карты внешнего круга идут в порядке возрастания углов (против часовой); если `False` – в порядке убывания (по часовой). |
| `INNER_ORDER` | `False` | То же самое для внутреннего круга (здесь `False` – значит по часовой). |

| `ZODIAC_NAME` | `18` | Названия знаков (Овен, Телец, …). |

| `CARD_NUM` | `12` | Римские номера карт (I, II, …). |
| `CARD_SYMBOL` | `28` | Основные символы арканов (∞, ☽, ♔, …) в центре карт. |

## 10. Внутренние элементы (не настраиваемые)

Некоторые параметры жёстко заданы в коде и не вынесены в `CONFIG`:

- **Толщина линии секторов зодиака** — `linewidth=2` (в `Wedge`).
- **Прозрачность секторов** — `alpha=0.15`.
- **Толщина рамок карт** — `linewidth=2.5` для внешней, `0.8` для внутренней.
- **Толщина глобальных стрелок** — `linewidth=2`.
- **Размер наконечников стрелок** — стандартный (`arrowstyle='->'`).
- **Стиль линий** — пунктир (`linestyle='--'`) для стрелок и глобальных дуг.
- **Смещение подписей планет под знаками** — `y_planet = y - 0.055 * scale` (задаётся в коде).

---

## 11. Как это всё взаимодействует

1. **SCALE** умножает почти все радиусы и размеры, делая карту крупнее.
2. **ZODIAC_SCALE** дополнительно увеличивает радиусы зодиакального круга, не затрагивая карты и стрелки.
3. **ZODIAC_WIDTH** регулирует толщину цветного кольца, не меняя его внешнего радиуса.
4. Размеры карт и их позиции задаются отдельно для внешнего и внутреннего круга.
5. Стрелки имеют свои радиусы и длины дуг (`span`).
6. Цвета и шрифты настраиваются независимо.

Изменяя эти параметры, вы можете адаптировать карту под любой визуальный стиль без правки основного кода.
